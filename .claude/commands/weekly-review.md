---
description: The Monday review, written from three commands. What needs a decision, the season position, the compliance state, then the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Do not write anything they do not support.

```
npm run packhouse -- attention
npm run packhouse -- season
npm run packhouse -- compliance
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Deliveries on the floor, held fruit, trays in store, open consignments, dispatched trays with proceeds missing.
2. **The one that cannot wait.** Any held delivery (spray window) and any export consignment blocked on assurance, by name. This section existing at all is an emergency; empty is the system working.
3. **The intake.** What is waiting on the grader and what is waiting on a diary, each with the grower who owes the paperwork.
4. **The store.** Coolroom state, aged pallets, and what should move this week.
5. **The money.** Each pool's position; any dispatched trays without proceeds get named, with the buyer being chased.
6. **The certificates.** GAP audits due or lapsed, with the booking that fixes each.
7. **The five things to do this week.** Picked from the attention list, weighted by market access first, condition second, money third, and say why each made the list.
8. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view` if the operator wants pages for a meeting: same numbers, the business's brand, and they print.

Numbers come from the commands. If a number is not in the output, it does not go in the review.
