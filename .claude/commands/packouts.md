---
description: Grading results across the season - packout percentage and class 1 share per run, the numbers growers ring about, with the trend visible per grower.
---

1. Run `npm run packhouse -- packouts` (or `--grower=` for one grower's trend).
2. Read it the way a grower would: packout is what survived the reject belt; class 1 share is the export money. A run well below that grower's usual is worth a sentence before they ring: check the grading note (`delivery <ref>`) for weather or condition remarks.
3. The per-delivery statement renders with `npm run docs` (packout-statement): the delivery, what it graded, the pallets, in the business's brand. A person sends it.
4. Comparing blocks or varieties across the season: `season` gives the totals; ask for a new view (`/new-view`) if the same comparison keeps coming up.
